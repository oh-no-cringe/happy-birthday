# Тебе, с любовью ♡

Мини-открытка ко дню рождения: конверт, четыре вопроса, торт со свечами и письмо. Статический сайт без сборки, зависимостей и внешних запросов. Подготовлен для просмотра на iPhone и компьютере.

## Посмотреть

Открой `index.html` в браузере или запусти в этой папке:

```sh
python3 -m http.server 4173
```

Затем открой `http://localhost:4173`. Для просмотра с iPhone в той же Wi-Fi сети используй адрес компьютера, например `http://192.168.1.10:4173`.

## Подставить ваши данные

В `content.js` меняются обращение `recipient`, подпись `signature`, абзацы поздравления `paragraphs` и список фотографий `photos`. Вопросы находятся в массиве `questions` в `app.js`.

В папку уже добавлены все шесть ваших фотографий в JPG. Для замены положи новые фотографии в `photos/` и пропиши относительные пути:

```js
{ src: "photos/01.jpg", caption: "ты + я", position: "50% 50%" }
```

Не начинай путь с `/`: относительные пути работают и на GitHub Pages внутри репозитория. Имена файлов чувствительны к регистру. Для портретов можно настроить кадрирование через `position`, например `"50% 25%"`. Лучше экспортировать фото в JPG шириной примерно 1000 пикселей, чтобы страница быстро открылась с телефона. При отсутствии фото или ошибке загрузки останутся иллюстрации.

## Выложить через GitHub Pages

1. Создай репозиторий на GitHub и загрузи **всё содержимое этой папки**, включая `photos/`. Файл `index.html` должен быть в корне репозитория.
2. В репозитории открой **Settings → Pages**.
3. В **Build and deployment** выбери **Deploy from a branch**.
4. Выбери свою основную ветку (`main` или другую), папку **/ (root)** и нажми **Save**.
5. После публикации ссылка появится на этой же странице. Обычно это `https://USERNAME.github.io/REPOSITORY/`.

Сайт и загруженные фотографии будут доступны по опубликованной ссылке. Секреты и личные данные, которые не хочется публиковать, в репозиторий не добавляй.

## Поведение на телефоне

- Кнопки высотой не менее 48 пикселей, учтены безопасные зоны iPhone.
- На узком экране фотографии расположены выше вопросов и по внешним краям.
- Свечи гаснут кнопкой. Микрофон, камера и установка приложения не нужны.
- Нет автоматического перелистывания: после ответа можно спокойно прочитать реакцию.
- Учитывается системная настройка уменьшения движения.
